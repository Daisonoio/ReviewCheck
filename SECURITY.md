## Security

If you believe you have found a security vulnerability in this repository, please report it to us as described below.

## Reporting Security Issues

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to the private [security channel](https://github.com/Daisonoio/ReviewCheck/security/advisories/new)

Please use the standard [GitHub report security template](https://github.com/github/securitylab/blob/main/docs/report-template.md)

## Injection and other sensitive Issues

We take injection vulnerabilities seriously whether the unsafe value comes from a user or from an LLM acting on their behalf. If you find one, please report it; we'll get back to you as quickly as we can.

## Important notes

Reviewcheck is a standalone tool that runs on your local machine. It doesn't have any connection to any server other than the LLM provider you configure
