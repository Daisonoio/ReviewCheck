## Security

If you believe you have found a security vulnerability in this repository, please report it to us as described below.

## Reporting Security Issues

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to the private [security channel] (https://github.com/Daisonoio/ReviewCheck/security/advisories/new)

Please use the standard [GitHub report security template](https://github.com/github/securitylab/blob/main/docs/report-template.md)
